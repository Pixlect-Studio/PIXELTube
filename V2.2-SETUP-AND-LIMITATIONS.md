# PIXELTube CODE MAX V2.2 — Admin Search

## What's new
- Added an **Admin → Search** page to the existing admin sidebar.
- Searches channels and videos together in the data already loaded by the app.
- Case-insensitive partial matching across channel names, handles, IDs, owner UIDs, descriptions, video titles, video IDs, video descriptions, video kind, and related channel metadata.
- Search results identify whether each result is a channel or a video.
- Channel results include a link to the channel; video results include a watch link and the existing admin delete action.
- Live filtering does not rerender the page while typing. The Clear button resets the search, count, and empty state.
- Preserved the existing PIXELTube UI, moderation routes, project layout, and custom-domain `CNAME` file.

## Use it
1. Open the Admin panel while signed in with an account the current app recognizes as an admin.
2. Click **Search** in the admin sidebar.
3. Search for a channel name, `@handle`, video title, channel/video ID, or owner UID.
4. Click **View channel** or **View video** to open the matching page.

## Scope and limitations
- Search filters the channel/video data currently loaded in the browser; it does not issue a server-side database search.
- This release does not add new Firebase rules or a trusted backend. Client-side admin checks are not a security boundary.
- No deployment or DNS changes were performed.
